The Core Problem Rigid Code Can't Solve

A hardcoded scanner treats every stock the same way — same thresholds, same rules, same parameters across all 3,500+ stocks. But breakout behavior differs wildly: a pharma stock forming a base after FDA approval behaves nothing like a metal stock coiling before a commodity cycle turn. Rules that work for large-caps fail on SME stocks. Thresholds calibrated for bull markets kill everything in corrections.

The LLM's real job isn't to "be smart" — it's to be contextual. It reads the situation each stock is in and adjusts judgement in ways no fixed parameter set ever can.

The 12 Integration Points — Layer by Layer

1 News & Catalyst Detection Critical Missing

Breakouts don't happen randomly — they're triggered by catalysts. A stock consolidating for 3 months breaks out because something changed: a quarterly result beat, a contract win, an analyst upgrade, a sector policy shift. Rigid code is blind to this.

What the LLM would do: Before recommending any stock, scrape NSE corporate announcements (/api/corporate-announcements — already accessible via the forensic module), recent Moneycontrol/ET headlines, and quarterly result filings. Feed them to the LLM with the question: "Is there an upcoming or recent catalyst for this stock that would trigger a breakout within a week?"
  • Quarterly results: If a stock is consolidating near resistance AND its Q-results are due in the next 5 days, that's a catalyst. LLM reads the consensus estimates and past beat/miss pattern.
  • Contract/order wins: NSE announcements saying "Company XYZ bags ₹500cr order" — LLM judges if this is material enough to trigger a breakout.
  • Analyst upgrades: A stock already near resistance getting a price target upgrade from a major broker — that's institutional buying pressure about to arrive.
  • Sector policy: Government announces PLI scheme for electronics — every electronics stock near resistance suddenly has a higher probability of breaking out.
Edge value: This alone could add 10-15% accuracy. A stock with a technical setup AND a catalyst breaks out far more reliably than one with just a chart pattern.

Data sources already available: NSE /api/corporate-announcements (in forensic_accounting.py), screener.in company pages (quarterly results), BSE notices API.

2 Chart Pattern Recognition via Description Critical Missing

The biggest failure of the current scanner: it finds "resistance" using fractal pivot math, but that math can't tell a genuine flat base from a trending stock's recent highs. We patched this with a flat-ceiling check, but it's still crude.

What the LLM would do: For each candidate stock, generate a text description of its chart: "Stock rose 45% from ₹200 to ₹290 over 4 months, then traded sideways between ₹270-290 for 6 weeks with declining volume. The last 5 days show a tight range of ₹285-290 with very low volume. Resistance at ₹290 tested 4 times." Ask the LLM: "Is this a genuine breakout setup, or is the code detecting a false pattern?"
  • The LLM can distinguish: "flat base" vs "descending triangle" vs "just noise near a random price"
  • It can identify patterns the rigid code doesn't check: ascending triangle, bull flag, cup & handle with a proper handle (the code's cup & handle detector was 0 wins in 16 trades)
  • It can spot red flags: "this stock gapped up on one huge volume day and has been drifting — that's not a base, that's distribution"
Edge value: Eliminates the #1 user complaint — "the charts have no pattern." The LLM acts as a human chartist reviewing every pick before it goes out.
3 Institutional Footprint via Bulk/Block Deal Intelligence Critical Missing

You already have BulkBlock.py that fetches bulk & block deal data from NSE and BSE, and an investor_registry.py that tracks known superstar investors (Ashish Kacholia, etc.). This data is NOT being used by either breakout scanner.

What the LLM would do: For each breakout candidate, check the last 30 days of bulk/block deals. Feed the deal data to the LLM: "RELIANCE had 3 bulk deals in the last 2 weeks: Goldman Sachs bought 2M shares, Morgan Stanley bought 1.5M shares, HDFC MF bought 800K shares. Stock is consolidating near ₹2800 resistance. Does this institutional buying pattern suggest a breakout is coming?"
  • Known buyer detection: investor_registry.py already maps superstar names (Kacholia, Dolly Khanna, etc.). LLM can judge: "Ashish Kacholia bought via bulk deal 10 days ago at ₹450. Stock is now at ₹480 near resistance at ₹490. High conviction — Kacholia typically gets in before breakouts."
  • Quantity vs price: LLM can judge whether the deal size is meaningful relative to the stock's float and daily volume.
  • Sell-side warnings: If a bulk deal shows a major SELLER (promoter reducing stake, PE fund exiting), the LLM should flag this as a breakout KILL signal.
Edge value: You're sitting on this data and not using it. Smart money buys BEFORE breakouts — this signal is worth 5-10% accuracy improvement on its own.
4 F&O Open Interest as Resistance/Support Confirmation Critical Missing

You have fno_max_oi.py that scans F&O max open interest strikes. For F&O stocks, the max call OI strike IS the resistance, and max put OI IS the support. This is market-consensus resistance, not just chart-based.

What the LLM would do: For F&O stocks in the breakout watchlist, cross-reference: "The chart says resistance is at ₹2800. The max call OI is at ₹2800 strike with 50 lakh contracts. This CONFIRMS the resistance. But put OI is building at ₹2700 — strong floor. If the stock breaks ₹2800, short-covering from those 50 lakh call sellers will turbocharge the breakout."
  • When chart resistance aligns with max call OI → breakout is explosive (short covering cascade)
  • When chart resistance does NOT align with OI → the "resistance" might be a false level
  • PCR (put-call ratio) shifts near the resistance level signal whether the breakout will hold
Edge value: For the ~200 F&O stocks, this adds a completely independent confirmation signal. OI-confirmed breakouts succeed at much higher rates than chart-only breakouts.
5 Sector Rotation & Relative Strength Context New

You have sector_momentum.py, nse_ready_sectors.py, sector_breadth.py, and stage_analysis.py. Together they tell you which sectors are leading, which are rotating in, and which stocks within those sectors are the strongest.

What the LLM would do: Instead of mechanically filtering "top 30% sectors," the LLM reads the full sector picture: "Pharma sector just entered Stage 2 this week (stage_analysis). Breadth is expanding — 70% of pharma stocks above 200 EMA (sector_breadth). RS vs Nifty 500 turned positive for the first time in 6 months (nse_ready_sectors). Within pharma, JAGSNPHARM is forming a flat base near resistance with a squeeze. This is a SECTOR ROTATION trade — highest conviction."
  • LLM identifies which sector is rotating in (not just ranking, but the dynamic — is it accelerating or decelerating?)
  • Stocks in freshly rotating sectors have much higher breakout success than stocks in stale leaders
  • LLM can identify theme plays: "Defence stocks are all consolidating simultaneously — sector breakout incoming"
6 FII/DII Flow Direction New

fii_flows.py fetches FII/DII daily and monthly flow data. FII stake trends are tracked in fii_stake_tracker.py. This macro flow direction is crucial context.

What the LLM would do: Before making ANY recommendations, the LLM reads the macro picture: "FIIs net sold ₹8,000cr in the last 5 sessions. DIIs bought ₹6,000cr. Net negative. However, FII selling is concentrated in large-caps while small/mid-caps are seeing DII accumulation. Breakout success in large-caps will be lower this week. Weight recommendations toward DII-backed mid-caps."
  • FII buying phase → large-cap breakouts succeed more
  • DII accumulation → mid/small-cap breakouts succeed more
  • Both selling → reduce position sizes, only highest conviction picks
  • LLM adjusts the scanner's confidence/sizing based on flow direction
7 Per-Stock Fundamental Quick-Check New

forensic_accounting.py and tickertape_client.py can fetch financials. A breakout in a fundamentally weak company is a trap — a breakout in a company with accelerating earnings is the real deal.

What the LLM would do: For each top-10 pick, quick-fetch the latest 2 quarters of revenue and profit growth from Tickertape. Feed to LLM: "Stock X: Revenue grew 35% YoY last quarter, profit grew 60% YoY. Price is consolidating near ₹500. This is a CANSLIM-style growth breakout — strongest conviction. vs Stock Y: Revenue flat, profit declining 10%. Price near resistance. This breakout is likely to FAIL — no fundamental support."
  • Earnings acceleration + technical breakout = highest conviction
  • Fundamental deterioration + near resistance = likely false breakout
  • Not a full forensic analysis — just 30-second growth check per stock
8 Dynamic Code Modification Edge

Currently the LLM suggests parameter changes as JSON. But the deeper improvements need actual CODE changes — new rules, new indicators, new gate logic.

What the LLM would do: After analyzing failure patterns, instead of just saying "add a rule for X", the LLM writes the actual Python code: a new function, a modified gate, an additional indicator calculation. This code is written to a plugin file that the scanner imports and applies. The LLM effectively becomes a developer that improves the scanner weekly.
  • New indicator discovery: "I noticed failures cluster when the 5-day VWAP is below the 20-day VWAP. Adding a VWAP cross check." → LLM writes the VWAP function and adds it as a gate.
  • Adaptive gate logic: "In weak markets, tighten proximity to -1% to +1%. In strong markets, allow -4% to +3%." → LLM writes an if/else that reads market regime and adjusts gates dynamically.
  • Feature engineering: LLM can create composite features the original coder didn't think of — "combine RS rating × squeeze tightness × delivery trend into a single conviction score"
Edge value: This is where the system becomes truly self-improving. The LLM doesn't just tune knobs — it builds new machinery.
9 Delivery Data Integration Data

jugaad-data returns DELIVERY QTY and DELIVERY % for every NSE stock. This is the single most powerful institutional signal in Indian markets — and it's NOT being used in the live scanner (only theoretically designed).

What the LLM would do: For each top candidate, fetch 20 days of delivery data via jugaad-data. The LLM interprets the pattern: "ANANDRATHI: Delivery % rose from 42% to 68% over the last 5 sessions while price stayed flat at ₹2200. This is STEALTH ACCUMULATION — institutions are buying heavily while the stock appears quiet. When it breaks ₹2215, the accumulated demand will push it hard."
  • Rising delivery + flat price = stealth accumulation (highest signal)
  • Falling delivery + rising price = retail FOMO, likely to fail
  • The LLM distinguishes these nuances that a simple delivery % threshold cannot
10 Intraday Breakout Trigger Monitoring Edge

The scanner runs after market close and recommends stocks. But the ACTUAL breakout might happen at 10:30 AM the next day. By the time the user sees the recommendation, the breakout is over.

What the LLM would do: For the daily watchlist, set up an intraday monitor: using Angel One's live market data (already accessible), check every 15 minutes during market hours if any watchlisted stock's price crosses its resistance level on above-average volume. When it does, the LLM composes a real-time alert: "🚨 BREAKOUT: ANANDRATHI crossed ₹2215 resistance at 10:45 AM on 2.3x average volume. Entry NOW at ₹2220, stop ₹2070, target ₹2430."
  • Transforms the scanner from "end-of-day report" to "live breakout alert system"
  • The LLM judges whether the intraday move is genuine (volume-confirmed) or a fakeout
  • Uses email_sender.py to push alerts immediately
11 Risk-Adjusted Position Sizing Edge

Currently every pick gets equal weight. But some setups are 95% conviction and others are 60%. The LLM should tell you not just WHAT to buy, but HOW MUCH.

What the LLM would do: For each pick, compute a conviction-adjusted position size: "TITAGARH: 9 resistance touches, BB/KC squeeze, OBV divergence, recent volume surge, sector (Rail) entering Stage 2, FII buying in capital goods — CONVICTION: 95%. Allocate 20% of breakout capital. vs BEPL: 2 touches, one signal, no squeeze — CONVICTION: 55%. Allocate 5% maximum."
12 Weekly Strategy Review & Rotation Edge

Once a week, the LLM does a comprehensive strategy review: reads all the data from the tracker history, sector flows, market regime, FII flows, and decides the OVERALL approach for the next week.

What the LLM would do: "Week review: Market corrected 3% this week. FIIs sold ₹12,000cr. Nifty below 50 DMA. However, pharma and FMCG sectors showed relative strength. 6 of 8 successful breakouts this week were in defensive sectors. STRATEGY FOR NEXT WEEK: Focus on pharma/FMCG/healthcare breakouts only. Raise minimum score to 65. Require OI confirmation for all F&O stocks. Reduce position sizes by 40%."

The Foolproof System — What It Looks Like When Everything Is Connected

Imagine the daily run 30 days from now:

Scanner finds 150 stocks with flat bases near resistance
Delivery data shows 40 of them have rising institutional accumulation
Bulk deal check shows 8 had superstar investor buying in the last month
F&O OI confirms resistance for 5 of those 8 (short-covering potential)
NSE announcements show 3 have upcoming results or recent order wins
Sector analysis shows 2 are in a freshly-rotating sector entering Stage 2
Tickertape check confirms 2 have accelerating earnings (35%+ growth)
LLM reads the full picture for each and writes a one-paragraph thesis
Final output: 2-3 stocks with technical + institutional + fundamental + catalyst alignment
Next day: intraday monitor catches the breakout at 10:30 AM, sends you an alert

Each layer is an independent filter. A stock that passes ALL of them has 6 independent reasons to break out. The probability of all 6 being wrong simultaneously is negligible. That's how you get to 90%+ — not by tuning one scanner's parameters, but by stacking independent confirmation signals and letting the LLM synthesize them.

What Makes This Different From Any Other Scanner

Every scanning tool on the market — Chartink, StockEdge, TradingView screeners — does one thing: applies fixed rules to price data. They can't read news. They can't check who bought in bulk deals. They can't cross-reference F&O OI with chart resistance. They can't adapt their rules based on what failed last week.

This system does all of that because the LLM is the glue. It reads structured data from 10+ sources (OHLCV, delivery, bulk deals, F&O OI, sector breadth, FII flows, corporate announcements, fundamentals) and synthesizes a judgement call that no fixed rule set can replicate. And it improves itself every week by analyzing its own mistakes.

The rigid code does the heavy lifting — scanning 3,500 stocks, computing indicators, detecting bases. The LLM does the judgement — reading context, filtering garbage, and connecting dots across data sources that were never designed to talk to each other.
